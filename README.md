# Hospital Management System (Full-Stack)

A complete **Hospital Management System** web application developed with **Java Spring Boot**, **Spring Data JPA**, **H2 Database**, and modern **HTML5 / CSS3 / JavaScript**.

---

## 🌐 Live Project Demo
- **Live Website URL:** [https://hospital-management-system-backend-6-iats.onrender.com](https://hospital-management-system-backend-6-iats.onrender.com)
- **GitHub Repository:** [https://github.com/Aravind-0049/hospital-management-system-backend](https://github.com/Aravind-0049/hospital-management-system-backend)

---

## 🚀 Features

- **Live Analytics Dashboard**: Real-time counter of total patients, doctors, appointments, and bills.
- **Patient Management**: Register patients, capture demographic & medical history, and view active patient records.
- **Doctor Management**: Add doctors with department and specialty details.
- **Appointment Scheduling**: Schedule patient appointments with assigned doctors, time slots, and status tracking.
- **Billing Management**: Generate bills with amounts, billing types, dates, and payment statuses.
- **Unified Full-Stack Architecture**: Frontend bundled directly into Spring Boot static resources for seamless single-URL deployment.

---

## 🛠️ Technology Stack

- **Backend:** Java 21, Spring Boot 4.x, Spring Data JPA, Hibernate, HikariCP
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API, Responsive Grid)
- **Database:** In-memory H2 Database (MySQL compatibility mode)
- **Deployment:** Render Cloud, Docker (Eclipse Temurin JDK 21)
